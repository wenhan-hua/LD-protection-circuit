# Direct dependencies only. Transitive packages (contourpy, fonttools, pillow,
# pyparsing, dateutil, …) are resolved by pip and deliberately not pinned here.
#
# These are minimum floors, not exact pins. The previous version of this file was
# a `pip freeze` with exact pins; on Python 3.13+ none of those releases have
# prebuilt wheels, so pip fell back to building numpy and scipy from source and
# effectively never finished. Floors let pip pick a release that has a wheel for
# whatever interpreter you are on, while still refusing versions too old for the
# APIs these scripts use. Upper bounds guard against the next major API break.
#
# Verified on Python 3.14.3 (resolves to matplotlib 3.11.2, numpy 2.5.5,
# scipy 1.18.1, schemdraw 0.23) and compatible back to Python 3.9.

matplotlib>=3.5,<4        # pyplot; all figures
numpy>=1.22,<3            # array maths throughout
scipy>=1.8,<2             # special.ellipk/ellipe (coil L), integrate.solve_ivp (sim)
schemdraw>=0.19,<1        # the two circuit schematics
